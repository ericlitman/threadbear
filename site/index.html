Attention before inference

Settled scans cost no model tokensThreadBear reads bounded local evidence every five minutes and skips Luna whenever structured evidence settles the work.
Structured evidence winsRuntime, errors, automation state, and valid agent footers settle work before semantic fallback.
Unresolved work stays smallOnly unresolved changed tasks enter fresh, non-persisted classifier sessions—Luna medium by default, never the years of control-task history.
Mutations recheck firstEvery native title operation rechecks task identity and title, then fails closed if it detects drift.

Each mark is followed by user-owned subject text, and the complete visible title is bounded to 60 UTF-16 units.

Small, private footprint

ThreadBear installs at ~/.local/bin/threadbear, keeps one private core.json under ~/.local/share/threadbear, and runs the user LaunchAgent org.litman.threadbear.

v1 binaries are not Developer ID signed or notarized. The installer verifies the published SHA-256 checksum and candidate self-test before installation.

Honest boundaries

ThreadBear observes tasks, stages guarded decisions, and changes titles only through Codex Desktop's native setter. It does not archive tasks, decorate titles with token counts, update itself in the background, edit Desktop caches, click through the UI, or maintain a configuration framework.
